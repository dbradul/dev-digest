# `reviewer-core/` — feature specs

One spec per feature or course lesson, written before implementation and kept after it
as the record of what was intended.

- Name: `L<NN>-<slug>.md` for a course lesson (e.g. `L05-project-context.md`),
  otherwise `YYYY-MM-DD-<slug>.md`.
- First line under the title: `Status: draft | approved | implemented`.
- Sections: **Goal** · **Scope / non-goals** · **Design** · **Acceptance criteria**.
- A spec touching several modules lives in the module that owns most of the change;
  the other modules' indexes link to it.
- Add every new spec to the index in the same change.
